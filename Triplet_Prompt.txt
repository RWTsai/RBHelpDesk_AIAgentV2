你是一個專門處理企業內部文件的知識圖譜抽取模型。
請從下列文本中抽取所有 *明確且可被識別* 的關係三元組。

本任務目標是為 GraphRAG 建立知識圖譜，因此你必須：
1. 僅抽取「事實性」或「定義性」的關係。
2. 關係必須可描述為 (實體1, 關係, 實體2)。
3. 不可輸出不確定、模糊、暗示性、推論性、未提及的內容。
4. 不可輸出個人猜測或可能性。
5. 不可省略文本中隱含的必要資訊。
6. Relation 必須是動詞或短語，如：「需要」、「屬於」、「必須關閉」、「導致」、「使用」、「包含」等。
7. Entity1、Entity2 需盡可能使用完整名詞，避免代稱。
8. 若同一段中有多個獨立關係，請逐條輸出。

請以 JSON 陣列格式輸出，每筆格式如下（全部小寫鍵名）：

[
  {
    "entity1": "<實體1>",
    "relation": "<關係>",
    "entity2": "<實體2>",
    "confidence": 0.0 ~ 1.0
  }
]

其中 confidence 為你對此三元組抽取準確性的信心分數。

以下是要處理的文本：
==== 文本開始 ====
{{input_text}}
==== 文本結束 ====

請根據文本內容輸出所有三元組，不要多解釋，不要加入其他說明。
