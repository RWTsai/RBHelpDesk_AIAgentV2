# 唯讀 SQL 共通規則

- 每個資料庫是一個 **source**，工具說明裡會列出有哪些、各自放什麼資料。先看清楚問題屬於哪一個，再用 `source` 指定。
- **不同 source 不能互相 JOIN**，它們是不同主機／不同連線。需要兩邊的資料就分兩次查，再自己對照。
- 只寫單一 SELECT，不要加分號、不要寫註解、不要用 `SELECT *`。
- 欄位名稱一律先用 `describe_table` 確認。查不到就說查不到，不要猜欄位、不要自己編表名。
- 字串條件用單引號；日期用 `'YYYY-MM-DD'`。
- 系統會自動加上 `TOP N` 並限制查詢時間，所以請盡量加 `WHERE` 縮小範圍，不要撈全表。
- 這是唯讀連線，任何新增／修改／刪除都做不到。使用者要求異動資料時，請他到該系統本身操作。
- 查到的數字要附上依據（哪張表、什麼條件），不要自行推算或補齊沒查到的值。
