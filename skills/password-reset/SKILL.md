# 密碼重設與帳號鎖定

## 回覆時必須包含
1. 先依知識庫內容回答該系統的作法（有查到的話）。
2. 附上自助式密碼恢復系統：https://pass.royalbase.com
3. 提醒：密碼修改完成後需要等待約 **15 分鐘** 同步到所有系統，這段時間不要重複嘗試登入，避免帳號又被鎖定。

## 注意
- 不要要求使用者在 LINE 上提供密碼。
- 自助系統無法解決時，提示可以輸入「真人客服」由資訊部協助。
